# MIDI → note.x MML Studio

ブラウザでMIDIの指定チャンネルをnote.x / MXDRV向けMMLへ変換するツールです。外部ライブラリやインストールは不要で、MIDIの読み込み・変換・試聴をブラウザ内で行います。

## 使い方

1. GitHub Pagesのページ、またはダウンロードした `index.html` をブラウザで開きます。
2. MIDIファイルを選び、対象チャンネル（1～16）を指定します。
3. 出力パートを入力します。例: `P-W`、`P-U`、`A-H`、`P,R,T`。
4. ペダル・同音再発音対策・クオンタイズを設定し、「変換する」を押します。
5. 元のMIDIチャンネルとMMLを試聴し、「MMLを保存」で保存します。

設定変更後は再変換してください。MMLテキストは直接編集でき、MML試聴と保存には編集後の内容を使います。

## 主な機能

- SMF Format 0 / 1の読み込みとチャンネル選択
- FMパート `A-H`、拡張PCMパート `P-W` への振り分け
- 指定パート数を超えた場合、発音開始が最も古い音を終了して新しい音を優先
- CC64のサステイン反映（64以上でオン、63以下でオフ）
- 長さ0の音符の省略と省略数表示
- 同音再発音対策のオン・オフ
- 開始位置の自動調整を伴うクオンタイズ
- 元チャンネルとMMLの簡易シンセ試聴、再生位置指定、ピアノロール表示
- MML編集とダウンロード

## 音数とサステイン

ペダル中に離鍵した音をペダル解除まで延長します。ペダルが最後までオンの場合はMIDIの終端まで延長します。パート数が足りない場合は古い音を切ります。

同音再発音対策の初期値はオフです。オンの場合は持続中の同音のパートを再利用し、直前の音を1クロック早く切ります。クオンタイズ有効時の隙間は1グリッドで、前の同音が1グリッドしかない場合は音長を保持し、隙間なしで次の音へ切り替えます。

元MIDIの長さ0の音と、48 PPQへの丸め後に長さ0になる音は省略します。割り当て時に指定パート数を超える同時和音によって長さ0の音が生じる場合など、保持できない条件ではエラーを表示します。

## クオンタイズ

初期値は無効です。無効時は元MIDIの時刻を維持し、MMLの48 PPQへの必要な丸めのみを行い、`%` のクロック表記で出力します。

有効時は指定音長をグリッド兼最短音長とし、ペダル反映後の選択チャンネルを対象に処理します。曲全体の開始を前後1グリッド未満の範囲で1クロックずつずらし、音符の開始・終了時刻の絶対補正量の合計が最小になる位置を選びます。同点ではシフトの絶対値が小さい方を優先します。

曲末とテンポ変更もグリッドに揃えます。音符・休符とも指定音長以上の `c16`、`r16`、`c8.` などで出力し、長音は `&` で接続します。開始シフト量と平均補正量を画面に表示します。元MIDI側の試聴にはクオンタイズを適用しません。

## PCM / FMでの使用

拡張PCMには対応PCMドライバとPDXが別途必要です。必要に応じてPDX名・PCMバンク番号を入力してください。

```text
note -p output.mml
```

PCM音符の実際の音程はPDXのサンプル配置に依存します。FM出力は仮音色 `@0` を同梱します。

## 試聴と制限

- 試聴はWeb Audioの簡易シンセで、PDXや実機音色は再現しません。
- リバーブ、コーラス、ピッチベンド、CC64以外のMIDIコントローラ、プログラム変更は変換しません。
- ベロシティは `v1`～`v15` に近似します。
- MML試聴は本ツールの出力書式に対応します。マクロ・ループ・LFOなどの未対応命令はエラーを表示します。
- SMF Format 2およびSMPTE時間形式には対応していません。
- note.x実機でのコンパイル・再生は未確認です。
- タブを隠すと試聴を停止します。

## データと依存関係

MIDI・MMLをサーバーにアップロードしません。HTML内に外部スクリプト、外部フォント、外部ライブラリへの依存はありません。音源データ、PDX、MIDI、note.x / MXDRV本体は含みません。

## GitHub Pages

リポジトリの **Settings → Pages** で **Deploy from a branch** を選び、`main` ブランチの `/ (root)` を指定して保存すると、`index.html` が公開されます。
