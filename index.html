MIDI → note.x MML PCM / FM

チャンネルを選び、使うパートを指定。サステインと発音数を調整して、演奏を聴き比べます。

1. MIDIを開く

SMF Format 0 / 1に対応。チャンネル番号は1～16です。

2. 出力を設定

FM: A～H ／ 拡張PCM: P～W
空きがなければ、発音開始が最も古い音を終了します。

選択チャンネルの開始・終了時刻の補正量合計が最小になるよう、曲全体の開始を自動調整します（1クロック単位）。

PCMの音階→サンプル配置はPDX側で用意してください。FM出力は仮音色@0を同梱します。

3. 聴き比べ

0:00 / 0:00

試聴はWeb Audioの簡易シンセです。MIDI側も選択チャンネルのみ。MML側は音数制限・ペダル・編集結果を反映します。原音色、PDX、リバーブ、コーラス、ピッチベンドは再現しません。

MIDIファイルを選んで開始してください。

4. MMLを編集・保存

MDX直接保存はP～Wのみ対応。PDX名を指定して変換後、「MDXを保存」を押してください。対応PCMドライバとPDXは別途必要です。

仕様と使い方

保存したHTMLをブラウザで開いてください。ネット接続は不要です。MIDIを読み込み、チャンネル・パートを選び「変換する」を押すと、下のMMLを保存できます。設定変更後は再変換してください。

192クロック／全音符（4分音符48）へ絶対時刻を丸めます。MIDIのテンポ変更を保持し、長い音は&で接続します。ベロシティはv1～v15に近似します。CC64以外のMIDIコントローラ、プログラム変更、ピッチベンドは出力しません。ペダルが最後までオンなら、ファイル終端まで延長します。

「同音再発音の対策」オンの場合は、同音が持続中ならそのパートを再利用します。元MIDIで長さ0の音や、丸め後に0クロックになる音は省略し、省略数を表示します。1クロックの無音を確保できない極端な連打は変換を中止して通知します。

クオンタイズ有効時は選択チャンネルのノート開始・終了の絶対補正量の合計を最小化します。1グリッド未満の範囲で整数クロックの開始シフトを全探索し、同点ならシフトの絶対値が小さい方を選びます。終了は開始より最低1グリッド後に配置します。ペダル延長後に処理し、元の長さ0の音は省略します。テンポ変更にも同じ開始シフトを適用し、最寄りのグリッドへ丸めます。曲末・テンポ変更位置もグリッドに揃え、音符と休符を指定音長以上の音長表記で出力します。同音再発音対策の隙間も1グリッドとします。直前の同音が1グリッドしかない場合は、その音長を保持し、隙間なしで次の音へ切り替えます。MIDI試聴側はクオンタイズしません。無効時もMMLの48 PPQへの丸めは必要です。

「MDXを保存」は編集中のP～Wの生成MMLをブラウザ内でコンパイルします。PCM8宣言と16パートのデータを出力し、未使用FMパートは終了命令だけを格納します。@、t、v、q、p、o、音符・休符、%音長、通常音長、付点、同音の&に対応します。FMパート・マクロ・ループ・相対オクターブなど未対応命令はエラーになります。PCM音符はPDXサンプル番号0～95（o0d+～o8d）として保存します。タイトル・PDX名は半角文字のみ対応です。OPMタイマーの分解能によりテンポには誤差があります。MDXの16ビットオフセットを超える大きさは出力しません。

MML試聴はこのツールが出力する書式に対応します（音符、休符、%、音長分母、付点、&、^、o、<>、t、q、v、@、p）。マクロ・ループ・LFOなどは非対応です。未対応の命令はエラーにして知らせます。MML音符は音高として試聴し、PCMサンプル番号の挙動は模擬しません。

note.x実機でのコンパイル・再生は未確認です。FMのo4cをMIDI60として扱います。MMLやMIDIはサーバーへ送信されません。

note.x / MXDRV用。試聴音色と実際のPCM・FM音色は異なります。
